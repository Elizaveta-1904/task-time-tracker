# Task Time Tracker

## 1. Описание проекта

Task Time Tracker — программный модуль учёта времени
для системы управления задачами, разработанный на Python.

Программа позволяет создавать задачи, запускать и
останавливать таймеры, учитывать затраченное время
и формировать отчёты.

## 2. Цель проекта

Разработка программного решения для контроля времени,
затрачиваемого на выполнение отдельных задач.

## 3. Основные возможности

- Создание и хранение задач.
- Запуск таймера для выбранной задачи.
- Остановка таймера.
- Подсчёт общего затраченного времени.
- Изменение статусов задач.
- Формирование отчётов.
- Сохранение отчётов в текстовый файл.

## 4. Структура проекта

| Файл | Назначение |
|---|---|
| timer.py | Учёт времени |
| task_manager.py | Управление задачами |
| reports.py | Формирование отчётов |
| main.py | Главный модуль программы |
| test_timer.py | Автоматическое тестирование |
| requirements.txt | Зависимости проекта |

## 5. Используемые технологии

- Python 3.12
- GitHub
- GitHub Actions
- unittest
- unittest.mock

## 6. Запуск программы

Для запуска необходимо установить Python 3.12.

В терминале выполнить:

```bash
git clone https://github.com/Elizaveta-1904/task-time-tracker.git
cd task-time-tracker
python main.py
```

## 7. Тестирование

Для запуска автоматических тестов используется команда:

```bash
python -m unittest -v
```

Тестирование также выполняется автоматически
с помощью GitHub Actions при отправке изменений
в основную ветку main.
